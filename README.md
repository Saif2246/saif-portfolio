## Featured Project

### KiroTrace

Offline-Oriented SecOps Monitoring & AI-Assisted Security Analysis

KiroTrace is a defensive security monitoring and AI-assisted analysis system designed around local telemetry, evidence grounding, controlled tool execution, audit logging, and session-aware security assistance.

Key capabilities:

- Security log aggregation
- CloudTrail analysis
- Linux SSH log analysis
- Firewall log analysis
- Log normalization
- Threat detection
- Event correlation
- Evidence-grounded RAG
- Local Ollama LLM
- Controlled security tools
- Docker sandbox execution
- Assistant audit logging
- Session and context management
- Local vector memory

Technologies:

Python, Streamlit, Ollama, RAG, Docker

## Development Philosophy

### Evidence First

Security decisions should be grounded in observable telemetry, documented context, and traceable evidence.

### Least Privilege

Access and execution should be restricted to what is actually required.

### Defense in Depth

Security should rely on multiple complementary controls rather than a single defensive mechanism.

### Automation with Guardrails

Automation should include explicit execution boundaries, validation, policy controls, and auditability.
